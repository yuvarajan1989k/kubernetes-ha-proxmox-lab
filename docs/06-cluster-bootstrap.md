# 06 — Cluster Bootstrap

## Initialize the First Control Plane

Run only on `learn-k8s-cp`:

```bash
sudo kubeadm init \
  --control-plane-endpoint "10.10.1.224:6443" \
  --service-cidr "10.96.0.0/12" \
  --upload-certs
```


## Configure kubectl

For the current non-root user:

```bash
mkdir -p ~/.kube
sudo cp /etc/kubernetes/admin.conf ~/.kube/config
sudo chown "$(id -u)":"$(id -g)" ~/.kube/config
chmod 600 ~/.kube/config
```

Verify:

```bash
kubectl get nodes
```

## Join Additional Control Planes

Use the control-plane join command generated by `kubeadm init` on:

```text
learn-k8s-cp1
learn-k8s-cp2
```

## Join Worker Nodes

Use the worker join command generated by `kubeadm init` on:

```text
learn-k8s-w1
learn-k8s-w2
learn-k8s-w3
```

## Final Verification

```bash
kubectl get nodes -o wide
```

Expected final state:

```text
3 control-plane nodes Ready
3 worker nodes Ready
```
